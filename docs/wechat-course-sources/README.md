# 微信教材资源缓存

本目录保存“向西家委会”发布的新版沪教牛津英语资源入口、文章快照、媒体目录和知识点统计，作为后续重写小程序教材数据的依据。

## 目录约定

- `sources.json`：用户确认的长期入口及访问状态。
- `raw/`：每篇微信文章的一次性结构化快照，包含标题、公众号、发布日期、正文、链接和媒体元数据。
- `catalog/`：按年级、学期和 Unit 整理的音频/视频目录。
- `subtitles/raw/`：开发期 ASR 原始结果和带校验信息的逐句时间轴，不进入小程序包。
- `summary.json`：课程数量、知识内容和资源覆盖率统计。
- `report.md`：面向人工阅读的最终课程与知识内容统计报告。
- `anomalies.json`：浏览器配置、页面延迟、微信验证及恢复记录。

## 采集原则

1. 使用用户指定并已连接的浏览器正常访问公开页面，不伪装身份、不绕过验证码或平台风控。
2. 每读取一篇文章立即写入 `raw/`，后续分析优先使用本地快照，避免重复访问微信。
3. 保存来源 URL、文章元数据、正文和公开媒体 URL；音视频二进制文件默认不下载，也不放入 `miniprogram/`。
4. 无法确认的年级、学期、Unit 或教材版本标记为 `unknown`，不得凭标题猜测。
5. 后续补充内容时保留历史快照，并在 `sources.json` 更新最后检查日期和状态。

## 字幕样板

一年级下册 Unit 1 已完成 6 段视频、70 条逐句双语字幕。开发期生成命令：

```powershell
npm run subtitles:unit1
```

脚本从微信云存储读取已归档媒体，缓存到清单指定的 `cacheRoot`，使用 FFmpeg 抽取 16kHz 单声道音轨，再调用腾讯云录音文件识别生成词级时间戳。原始结果保存在 `subtitles/raw/`，人工校对后的运行时数据位于 `miniprogram/data/subtitles/`。

Unit 1 音频文章因 Browser 插件连接异常暂未归档，恢复步骤见 `anomalies.json`。
